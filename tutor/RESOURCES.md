# Transformers and Attention Resources

## Knowledge

- [Paper: "Attention Is All You Need" by Vaswani et al. (2017), arXiv HTML](https://arxiv.org/html/1706.03762v7)
  The original transformer paper; Sections 3.2 and 4 define scaled dot-product and multi-head attention and compare them with RNNs and CNNs. Use for: exact formulas, the sqrt(d_k) variance footnote, the h = 8 / d_k = 64 setup, complexity per layer.
- [Paper PDF: "Attention Is All You Need"](https://arxiv.org/pdf/1706.03762)
  The same paper as a PDF. Use for: printing and annotating.
- [Textbook: Dive into Deep Learning, 11.3 Attention Scoring Functions](https://www.d2l.ai/chapter_attention-mechanisms-and-transformers/attention-scoring-functions.html)
  Open textbook chapter with the variance argument, masked softmax and runnable code. Use for: implementation details and code to adapt for the learner's project.
