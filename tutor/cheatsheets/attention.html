Scaled dot-product attention

Attention(Q, K, V) = softmax( Q KT / √dk ) V

The four moves

  1. Score: Q KT, every query dotted with every key (n × n).
  2. Scale: divide by √dk, so scores keep unit variance.
  3. Normalize: softmax each row; weights are positive and sum to 1.
  4. Mix: multiply by V; each output is a weighted average of values.
