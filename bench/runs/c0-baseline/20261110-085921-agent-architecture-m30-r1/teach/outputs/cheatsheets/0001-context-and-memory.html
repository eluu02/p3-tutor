Context and memory in an agent

From lesson 1.

Key terms

  • Context: all the text the model reads in one call (system prompt, tool descriptions, message history, notes, retrieved chunks).
  • Context window: the most tokens one call can hold, input and reply together.
  • Context rot: recall of details gets worse as the context grows.
  • Compaction: replace old history with a summary.
  • Retrieval: search documents, put only the best chunks into the context.

Rules to remember

  • The model keeps nothing between calls. Your program resends the whole history every call.
  • Cost of a request = sum of the context sent on every call, not the final size.
  • Between sessions nothing survives unless you save it and load it back.
  • Trim tool results to what is needed.
