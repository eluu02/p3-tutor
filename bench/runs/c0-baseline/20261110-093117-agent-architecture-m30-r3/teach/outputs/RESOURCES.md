# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source on context as a finite resource, just-in-time retrieval, compaction and note-taking. Use for: what to put in an agent's context and how to keep it small.
- [Docs: "Understanding the context window" (Claude Platform docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  Official explanation of how the window counts input and output, and what happens as it fills. Use for: window sizes and limits (check the page for current numbers).
- [Docs: "How to implement contextual RAG from Anthropic" (Together AI)](https://docs.together.ai/docs/how-to-implement-contextual-rag-from-anthropic)
  Implementation guide for contextual retrieval over chunked documents. Use for: building the manual search.
