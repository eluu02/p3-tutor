Context and memory in an agent

From lesson 1.

Terms

  • Context: all text sent to the model on one call. Context window: the limit on its size, in tokens.
  • Memory: information saved outside the model and loaded back into a later context.
  • Retrieval: searching stored chunks and putting only the best into the context.
  • Compaction: summarizing a long history to continue with less text.

Rules

  • The model keeps nothing between calls; the program re-sends the history.
  • Input tokens for a request = sum of every call's whole context, so growth compounds.
  • Keep tool results small; they are re-sent on every later call.
  • Save short, stable, dated facts; do not save transcripts or fast-changing data.
  • Keyword search finds exact words; embedding search finds similar meaning; combine them.
